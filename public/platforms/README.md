# Ícones das Plataformas (Game Hub)

Coloque aqui os ícones PNG de cada plataforma com os seguintes nomes de arquivo:

- `steam.png` (Ícone da Steam)
- `epic.png` (Ícone da Epic Games)
- `gamepass.png` (Ícone do Xbox Game Pass)
- `ea.png` (Ícone da EA App)
- `ubisoft.png` (Ícone do Ubisoft Connect)
- `suspeitos.png` (Ícone da coleção Suspeitos / Repacks / Standalone)

Caso algum arquivo de imagem ainda não esteja presente, o GamerVault Hub exibirá automaticamente ícones visuais modernos do Lucide com estilo neon como fallback.
